# homebrew-pane

Homebrew tap for [Pane](https://github.com/abhishek-verma/Pane) — a browser with a built-in personal agent.

## Install

```sh
brew install --cask abhishek-verma/pane/pane
```

Or add the tap first:

```sh
brew tap abhishek-verma/pane
brew install --cask pane
```

## Update

```sh
brew upgrade --cask pane
```

## About

Pane is an open-source Chromium browser with a personal agent built into the session you already use.
macOS Apple Silicon (arm64) only.

[→ Pane on GitHub](https://github.com/abhishek-verma/Pane)
